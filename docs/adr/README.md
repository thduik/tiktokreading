# ADR Index

Use Architecture Decision Records (ADRs) for choices that affect future implementation.

## Naming

- Format: `NNNN-short-title.md`
- Example: `0001-official-doc-system.md`

## ADR Template

```md
# ADR NNNN: Title

- Date: YYYY-MM-DD
- Status: Proposed | Accepted | Superseded

## Context

What problem are we solving?

## Decision

What did we choose?

## Consequences

What does this enable, and what tradeoffs did we accept?

## Alternatives Considered

- Option A
- Option B
```
